
## Traffic Light CODE ##
### DESCRIPTION ###
Code written in Structured Text (ST) that simulates a traffic light with a pedestrian crossing phase, using CODESYS.

### VARIBALE DECLARATION ###
pedestrian button input, vehicle and pedestrian light outputs, state variable, and timers.

### PROGRAM LOGIC (ST) ###
Main traffic light logic, implemented as a state machine with 4 phases (red, green, yellow, pedestrian crossing), controlled by timers.
